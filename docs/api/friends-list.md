# Получение списка друзей

Метод возвращает страницу друзей пользователя.

Другом считается пользователь, с которым уже создана двусторонняя связь дружбы. Такая связь появляется после принятия предложения дружбы и перехода заявки в состояние `ACCEPTED`.

## HTTP-запрос

```http
GET /api/v1/friendships?userId=0b6f3c9e-6a1d-4c2e-9f5a-2d7b8e1c4a01&limit=20
Accept: application/json
```

## Query-параметры

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `userId` | `string (uuid)` | Да | Идентификатор пользователя, для которого нужно получить список друзей. |
| `limit` | `integer` | Нет | Размер страницы, 1..100, по умолчанию 20. |
| `afterCreatedAt` | `string (date-time)` | Нет | `next.createdAt` предыдущей страницы; задаётся вместе с `afterId`. |
| `afterId` | `string (uuid)` | Нет | `next.id` предыдущей страницы; задаётся вместе с `afterCreatedAt`. |

## Успешный ответ

API возвращает статус `200 OK` и страницу друзей.

```http
HTTP/1.1 200 OK
Content-Type: application/json
```

```json
{
  "friends": [
    {
      "id": "c1d2e3f4-5a6b-4c7d-8e9f-0a1b2c3d4e02",
      "userId": "7d1f0a52-2b8e-4c9a-b3d6-4e8f1a2c5b66"
    }
  ],
  "next": null
}
```

Если друзей нет, API возвращает пустую страницу.

```json
{ "friends": [], "next": null }
```

### Поля ответа

| Поле | Тип | Описание |
| --- | --- | --- |
| `friends` | `array` | Друзья страницы. |
| `friends[].id` | `string (uuid)` | Идентификатор дружбы. |
| `friends[].userId` | `string (uuid)` | Идентификатор пользователя-друга (второй участник дружбы). |
| `next` | `object \| null` | Курсор следующей страницы `{createdAt, id}` — позиция последней дружбы; `null` — друзей больше нет. |

## Правила обработки

- Метод возвращает только пользователей, с которыми у пользователя `userId` есть связь дружбы.
- Заявки в состоянии `PENDING` не считаются дружбой и не попадают в список друзей.
- Заявки в состоянии `REJECTED` не считаются дружбой и не попадают в список друзей.
- Возвращаются только активные дружбы (`status = ACTIVE`).
- Порядок — от новых дружб к старым: `createdAt DESC` дружбы, при равенстве — `id DESC`.
- Страницы читаются по курсору: первая — без `afterCreatedAt`/`afterId`, следующая — с `afterCreatedAt = next.createdAt` и `afterId = next.id`.
- Нет друзей или неизвестный пользователь — пустая страница, а не ошибка.

## Идемпотентность

Метод только читает данные и не изменяет состояние системы.

- Повторный вызов не создаёт и не удаляет дружбу.
- Повторный вызов не создаёт подписки.
- При неизменных данных повторный вызов возвращает тот же список друзей.

## Возможные ошибки

| HTTP-статус | Ситуация |
| --- | --- |
| `400 Bad Request` | `userId` нет или не UUID; `limit` вне 1..100 или не число; `afterCreatedAt` не дата-время; `afterId` не UUID; задана только одна часть курсора. |
